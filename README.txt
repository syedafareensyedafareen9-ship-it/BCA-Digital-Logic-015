DIGITAL LOGIC AND COMPUTER ARCHITECTURE LAB - LOGISIM EVOLUTION

20 individual .circ project files are included (prog1.circ through prog20.circ).
They follow the experiment order in the uploaded BCA I Semester lab manual.

Open each file with Logisim Evolution using File > Open. Toggle input pins and
use the Poke tool to test the combinational circuits.

IMPORTANT COMPATIBILITY / REVIEW NOTES
- The files use the Logisim Evolution XML project format (3.9.0 project source).
- Experiments 1-13 include gate-level editable circuit components and labelled pins.
- Experiments 14 and 20 use built-in 4-bit comparator/adder components.
- Experiments 15-18 use flip-flop/counter components as editable starting layouts.
- Experiment 19 includes the arithmetic/logic blocks and mux layout; verify pin
  placement and selector configuration in your installed Logisim Evolution build.
- The source manual contains a few ambiguous/typo-prone diagrams; compare each
  circuit against its corresponding manual page and test all truth-table rows.

These are editable circuit project files, not screenshots. Component placement and
wire-anchor behavior can vary slightly between Logisim Evolution releases.

Validation note: XML syntax has been checked. The projects have not been opened in a live Logisim Evolution installation in this environment, so please verify pin/wire placement and simulate each experiment before classroom or assessment use.
